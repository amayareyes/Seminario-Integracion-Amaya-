# Seminario de Integración - Sistema de Visión Astronómica

Repositorio de práctica de Git y GitHub para el proyecto *Sistema de Visión Artificial para la Identificación y Clasificación Automatizada de Objetos Celestes*.

## Problema y objetivo

**Problema.** Los observatorios y sondeos astronómicos generan cada vez más imágenes del cielo, y su clasificación todavía depende de la revisión manual de especialistas o de algoritmos tradicionales que pierden exactitud con ruido o bajo contraste. Esto vuelve lenta e inconsistente la catalogación y deja imágenes sin analizar.

**Objetivo medible.** Desarrollar un sistema basado en redes neuronales convolucionales (CNN) que clasifique imágenes astronómicas en estrellas, galaxias y nebulosas con una exactitud mínima de 85 % y un tiempo de inferencia menor a 2 segundos por imagen.

**Siguiente paso.** Seleccionar y documentar los datasets públicos de estrellas, galaxias y nebulosas que se usarán para entrenar y evaluar el modelo (tarea T02 del backlog).
